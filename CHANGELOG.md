# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-01-19

### Added

- Initial release
- GitHub Copilot Chat Model node for n8n AI Agent workflows
- OAuth device flow authentication via GitHub
- Dynamic model discovery from Copilot API
- Premium model indicators with request multipliers ([3x], [1x], [0.33x] badges)
- Support for GPT-4, Claude, Gemini, and other models through Copilot subscription
- Temperature configuration (0-2 range)
- Searchable model dropdown with live API data
