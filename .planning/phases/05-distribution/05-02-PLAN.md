<tasks>

<task type="auto">
  <name>Task 1: Verify package contents and npm login</name>
  <files></files>
  <action>
1. Run `npm whoami` to verify logged into npm registry
   - If not logged in, this will error - create checkpoint for user to run `npm login`

2. Run `npm pack --dry-run` to preview package contents
   - Verify only dist/ files will be included
   - Check total package size is reasonable (should be < 50KB)

3. Run `npm run build` to ensure fresh build
   - Verify dist/ directory contains compiled output

4. Verify package.json version is "1.0.0"
   - If not 1.0.0, warn user (version already published cannot be re-published)
  </action>
  <verify>npm whoami returns username; npm pack --dry-run shows only dist/ files</verify>
  <done>npm login verified, package contents correct, build fresh</done>
</task>

<task type="auto">
  <name>Task 2: Publish to npm registry</name>
  <files></files>
  <action>
1. Run `npm publish --access public`
   - The --access public flag ensures the unscoped package is public
   - prepublishOnly script will run build automatically

2. Verify publication with `npm info n8n-nodes-github-copilot`
   - Should show package metadata
   - Version should be 1.0.0

3. Test installation locally (optional sanity check):
   - `npm pack` creates tarball
   - Verify tarball contains expected files
  </action>
  <verify>npm info n8n-nodes-github-copilot returns package metadata with version 1.0.0</verify>
  <done>Package published to npm, visible at https://www.npmjs.com/package/n8n-nodes-github-copilot</done>
</task>

<task type="checkpoint:human-verify" gate="blocking">
  <what-built>Published n8n-nodes-github-copilot package to npm registry</what-built>
  <how-to-verify>

2. Verify the package page shows:

   - Version: 1.0.0
   - README content visible

3. Test installation in n8n:

   - Verify node appears with correct icon

4. (Optional) Quick functional test:
