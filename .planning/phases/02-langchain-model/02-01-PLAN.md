Create `src/lib/CopilotChatModel.ts` implementing a LangChain BaseChatModel that wraps ChatOpenAI.

**Class structure:**

```typescript
interface CopilotChatModelParams {
  tokenManager: CopilotTokenManager;
  temperature?: number;  // 0-2, default 0.7
  verbose?: boolean;
}

class CopilotChatModel extends BaseChatModel {
  // Private fields
  private tokenManager: CopilotTokenManager;
  private temperature: number;

  // Required BaseChatModel methods
  _llmType(): string  // Return 'github-copilot'
  async _generate(messages, options, runManager?): Promise<ChatResult>

  // Helper methods
  private transformMessages(messages: BaseMessage[]): BaseMessage[]
  private createInnerModel(token: string, endpoint: string): ChatOpenAI
}
```

**Implementation details:**

1. **Constructor:**
   - Accept CopilotChatModelParams
   - Validate temperature (throw if outside 0-2 range)
   - Store tokenManager and temperature (default 0.7)
   - Call super({ verbose: params.verbose })

2. **_llmType():**
   - Return 'github-copilot' (used by LangChain for logging/tracking)

3. **_generate() method:**
   - Call `this.tokenManager.getValidToken()` to get fresh token + endpoint
   - Create ChatOpenAI instance with:
     - openAIApiKey: token
     - configuration.baseURL: endpoint (NOT endpoint + /chat/completions)
     - temperature: this.temperature
     - modelName: 'gpt-4o' (hardcoded default, Phase 3 makes configurable)
   - Transform messages (system -> assistant)
   - Delegate to ChatOpenAI._generate()
   - Return the ChatResult

4. **transformMessages():**
   - Map over messages
   - For messages where _getType() === 'system', convert to AIMessage with same content
   - Keep all other messages unchanged
   - Log transformation if verbose mode (use this.verbose from base class)

5. **Error handling:**
   - Wrap _generate in try/catch
   - For 401/403 errors: attempt token refresh once, retry
   - For 429 errors: let ChatOpenAI's retry handle it
   - Transform technical errors to user-friendly messages

**Imports needed:**
- BaseChatModel, type BaseChatModelCallOptions from @langchain/core/language_models/chat_models
- BaseMessage, AIMessage from @langchain/core/messages
- ChatResult from @langchain/core/outputs
- CallbackManagerForLLMRun from @langchain/core/callbacks/manager
- ChatOpenAI from @langchain/openai
- CopilotTokenManager from ./CopilotTokenManager

**Important notes:**
- Create ChatOpenAI fresh on each _generate() call (token may have changed)
- The baseURL should be just the endpoint (e.g., "https://api.githubcopilot.com") - ChatOpenAI appends the path
- Include JSDoc comments explaining the class purpose and key methods
