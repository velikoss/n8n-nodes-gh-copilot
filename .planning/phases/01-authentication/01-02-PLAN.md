<task type="auto">
  <name>Task 1: Implement token manager</name>
  <files>src/lib/CopilotTokenManager.ts</files>
  <action>
Create src/lib/CopilotTokenManager.ts implementing Copilot token exchange and management:

1. Define CopilotTokenResponse interface:
   - token: string (JWT for Copilot API)
   - expires_at: number (Unix timestamp in seconds)
   - endpoints?: { api?: string } (dynamic endpoint)

2. Implement getCopilotToken(oauthToken: string): Promise<CopilotTokenResponse>:
   - GET https://api.github.com/copilot_internal/v2/token
   - Headers: Authorization: Bearer {oauthToken}, Accept: application/json
   - Handle errors:
     - 401: "Invalid OAuth token. Please re-authenticate."
     - 403: "No active Copilot subscription found."
     - Other: "Token exchange failed: {status}"
   - Return CopilotTokenResponse

3. Implement CopilotTokenManager class:
   - Constructor(oauthToken: string, savedEndpoint?: string)
   - Private fields: oauthToken, apiToken, expiresAt, apiEndpoint
   - getValidToken(): Promise<{ token: string; endpoint: string }>
     - Check if token exists and has >5 minutes remaining
     - If not, call refreshToken()
     - Return { token, endpoint }
   - Private refreshToken(): Promise<void>
     - Call getCopilotToken()
     - Store apiToken, expiresAt (convert to milliseconds)
     - Update apiEndpoint if response.endpoints.api exists
   - getEndpoint(): string - return current endpoint

4. Export: CopilotTokenManager, getCopilotToken, CopilotTokenResponse

IMPORTANT: Never hardcode the Copilot API endpoint. Always use the endpoint from token exchange response. This is critical for Business/Enterprise SKU support (AUTH-05).
  </action>
