<task type="auto">
  <name>Task 2: Implement device code flow</name>
  <files>src/lib/CopilotAuth.ts</files>
  <action>
Create src/lib/CopilotAuth.ts implementing RFC 8628 device authorization grant:

1. Define interfaces:
   - DeviceCodeResponse: device_code, user_code, verification_uri, expires_in, interval
   - TokenResponse: access_token, token_type, scope

2. Define CLIENT_ID constant:
   - Use "Iv1.b507a08c87ecfe98" (VSCode Copilot client ID)
   - Add comment noting this is the well-known VSCode client ID

3. Implement requestDeviceCode():
   - POST to https://github.com/login/device/code
   - Body: { client_id, scope: "read:user" }
   - Headers: Content-Type: application/json, Accept: application/json
   - Return DeviceCodeResponse
   - Throw descriptive error on non-200 response

4. Implement pollForToken(deviceCode: string, interval: number, expiresAt: number):
   - Poll https://github.com/login/oauth/access_token
   - Body: { client_id, device_code, grant_type: "urn:ietf:params:oauth:grant-type:device_code" }
   - Handle RFC 8628 error cases:
     - authorization_pending: continue polling
     - slow_down: add 5 seconds to interval
     - expired_token: throw "Device code expired. Please restart authorization."
     - access_denied: throw "User denied authorization."
   - Return access_token on success
   - Use async/await with sleep helper

5. Implement sleep(ms: number) helper function

6. Export: requestDeviceCode, pollForToken, DeviceCodeResponse, CLIENT_ID
  </action>

Run: npx tsc --noEmit
Confirm: No TypeScript errors, all exports are accessible
  </verify>
  <done>CopilotAuth.ts exports requestDeviceCode and pollForToken functions that correctly implement RFC 8628 device authorization flow with all error cases handled</done>
